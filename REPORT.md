### Зависимости и группы

Основные зависимости:

- `requests` — запрос данных через HTTP;
- `pandas` — создание, сортировка и сохранение таблицы;
- `matplotlib` — построение и сохранение графика.

Инструменты разделены по группам:

- `pytest` находится в группе `test`;
- `ruff` находится в группе `dev`.

Примеры транзитивных зависимостей:

- `requests` → `urllib3`;
- `pandas` → `numpy`;
- `matplotlib` → `pillow`.

Точные версии прямых и транзитивных зависимостей зафиксированы в
`poetry.lock`.

### Проверка групп

| Установленные группы | pytest | ruff | Основной скрипт |
|---|---:|---:|---:|
| Только `main` | нет | нет | работает |
| Только `test` | да | нет | не работает |
| Полное окружение | да | да | работает |

При установке только `main` доступны библиотеки, необходимые программе, но
инструменты тестирования и разработки отсутствуют.

При установке только `test` доступен `pytest`, но основной скрипт не
запускается, поскольку отсутствуют `requests`, `pandas` и `matplotlib`.

Команда `poetry sync` восстановила полное окружение со всеми группами.
Тест запускается командой:

```bash
poetry run python -m pytest
```

Результат: `1 passed`.

### Точечное обновление зависимости

Для `requests` используется ограничение:

```text
>=2.34.2,<3.0.0
```

Оно разрешает совместимые обновления в пределах версии 2.x и запрещает переход
на следующую мажорную версию 3.x.

Команда `poetry show --outdated` не обнаружила устаревших зависимостей. После
`poetry update requests` установленная версия осталась `2.34.2`.
`pyproject.toml`, `poetry.lock` и транзитивные зависимости не изменились,
поскольку более новой совместимой версии не было.

## Сравнение подходов

В варианте `venv + pip` изоляцию обеспечивает модуль `venv`, а точные версии
пакетов фиксируются в `requirements.txt`, созданном через `pip freeze`.
Файл содержит прямые и транзитивные зависимости без явного разделения.

Poetry хранит прямые зависимости и их допустимые диапазоны в
`pyproject.toml`, а точные версии полного дерева зависимостей — в
`poetry.lock`. Poetry также поддерживает отдельные группы для основных,
тестовых и разработческих зависимостей.

В обоих случаях воспроизводимость была подтверждена удалением `.venv`,
созданием нового окружения и повторным запуском программы.
